# Analysis and model inputs

[← Overview](../README.md) · [Reproduce](../docs/REPRODUCING.md)

## Files and observation units

| Included input | Unit / size | Producer → consumer |
| --- | --- | --- |
| [cases.csv](cases.csv) | One simulation case; 170 rows | Original run index and SQL audit → analysis and batch runner |
| [monthly_zone_loads.csv](monthly_zone_loads.csv) | One run × conditioned zone × month; 8,148 rows | Original EnergyPlus SQL extraction → annual calculation |
| [geometry/floor_categories_m.geojson](geometry/floor_categories_m.geojson) | Drawing-derived floor polygons, metres | Original geometry archive → baseline model generator |
| [geometry/gridded_footprints.geojson](geometry/gridded_footprints.geojson) | Actual gridded footprints, metres | Original plotting archive → geometry figures |

The common parameters are in [configs/model_parameters.json](../configs/model_parameters.json).
Archived results and QA records are in [reference/](../reference/README.md).

## Identifiers, fields and units

`result_id` joins the case index, monthly inputs and annual reference table.
`zone` identifies a conditioned zone within one run; `month` is 1–12.
Groups are `baseline` (4), `geometry` (6), `ofat` (64) and `factorial` (96).

| Field | Definition and unit |
| --- | --- |
| `source_batch` | Original research-archive label |
| `prototype`, `condition` | Scenario and sensitivity-condition identifiers |
| `conditioned_m2` | Actual SQL conditioned-zone floor area, m² |
| `changed_levels_json` | Inputs changed from the common baseline |
| `model_path`, `idf_sha256` | Repository-relative IDF path and byte hash |
| `source_sql_sha256` | Original SQL identity; not the expected byte hash of a new solver run |
| `heating_J`, `cooling_J` | Monthly supply-air **total** IdealLoads energies, J; sensible plus latent |
| `annual_heating_J`, `annual_cooling_J` | Annual sums in the reference table, J |
| `heating_kWh_per_m2_a`, `cooling_kWh_per_m2_a`, `ideal_total_kWh_per_m2_a` | Annual ideal thermal-demand intensities, kWh/m²/year |

Conversion: joules / 3,600,000 / conditioned m². Values are not rounded before
calculation or comparison. Warning fields retain original metadata; they do not
estimate numerical uncertainty. See [validation](../docs/VALIDATION.md).

## Availability

All files linked above and all [170 IDFs](../models/) are bundled. Numerical
reproduction needs no external data. The full original SQL databases remain in
the research archive; fresh SQL outputs can be generated by running EnergyPlus.
EnergyPlus 26.1.0 and the specified Taiyuan CSWD weather file are external
dependencies. Their identities and weather checksum are recorded in
[source_manifest.json](../source_manifest.json); acquisition and commands are in
[REPRODUCING.md](../docs/REPRODUCING.md).
